# ☕ Coffee Shop Sales Analysis Dashboard

Welcome to the **Coffee Shop Sales Analysis** project — a comprehensive Power BI dashboard that provides actionable insights into the sales performance of a coffee shop business. This project highlights my ability to clean, model, and visualize data effectively using Microsoft Power BI.

---

## 📁 Project Details

- **Project Title:** Coffee Shop Sales Analysis  
- **Tool Used:** Microsoft Power BI  
- **File:** `Coffee Shop Sales.pbix`  
- **Dataset Type:** Transactional sales data from a coffee shop  
- **Skills Demonstrated:** Data visualization, data modeling, DAX calculations, storytelling with data  

---

## 📊 Dashboard Highlights

The dashboard is designed to help business owners and stakeholders monitor performance and identify opportunities for growth. It includes the following insights:

✅ **Total Revenue, Units Sold & Average Transaction Value**  
✅ **Monthly & Daily Sales Trends**  
✅ **Top-Selling Products & Product Categories**  
✅ **Peak Sales Hours & Time-Based Patterns**  
✅ **Performance Comparison by Category & Product Line**  
✅ **Interactive Filters for Dynamic Exploration**

---

## 🎯 Objectives

- To analyze and understand sales patterns in a coffee shop business  
- To identify high-performing products and peak business hours  
- To assist in decision-making using visual storytelling  
- To practice real-world Power BI report development

1. **Download the repository** or clone it:
